Live Google Sheets setup

This version uses Google Apps Script as a live JSON endpoint. It can read from and write to the sheet without CSV publishing.

Google Sites testing note

Google Sites usually works best by embedding this site in an iframe from a host like GitHub Pages, Netlify, Vercel, or Google Drive preview. New Google Sites is not a normal static file host for multiple HTML/CSS/JS files.
